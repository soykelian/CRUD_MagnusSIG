# Prototipo de consola archivado

`inventario.py` es el MVP educativo inicial de Magnus SIG. Se conserva como referencia histórica de la fase de consola, pero ya no es el sistema operativo ni comparte datos con la aplicación web.

El producto actual es la aplicación Django ubicada en `magnus_sig/`. Para iniciarla, sigue las instrucciones de **Iniciar la aplicación web** en el README principal.
